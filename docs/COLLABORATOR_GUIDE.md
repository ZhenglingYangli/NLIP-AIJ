# MatriCS 操作手册入口

完整且维护中的操作步骤已集中到 [NLIP-AIJ 实验方案与 MatriCS 完整操作手册](EXPERIMENT_HANDBOOK.md)。请按该文档第 4 部分从头执行。

- [4.1 登录和取得源码](EXPERIMENT_HANDBOOK.md#41-先填写本站信息再取得源码)
- 第 4.2 节填写本机 `matrics.env`，标明模块、解释器、数据和许可证设置。
- 第 4.3 节下载并解包 SCIP、固定源码依赖和两个 MSE 发行包。
- 第 4.4 节安装 Python 环境并核对实际 SCIP 本体。
- 第 4.5 节编译三个外部程序并检查依赖。
- 第 4.6 节生成本站配置并写入已经核对的版本。
- 第 4.7 至 4.10 节完成计算节点检查、小测、正式实验与收结果。
- 第 4.11 节说明下次登录如何恢复环境，第 5 部分说明如何修改实验配置。

手册提供全部固定源码的在线下载命令。`nlip-solver-sources-20261124.tar.gz` 是由交付者提供的可选离线备用包，不随 `git clone` 下载。MatriCS 的模块名、数据目录和许可证须按账户填写。文档中的【必改】【条件修改】【需要管理员】均须在对应步骤处理。
